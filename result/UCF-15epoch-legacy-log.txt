
MA-RUPA: Modality-Adaptive Multiscale Prototype Alignment Network
Weakly-Supervised Video Anomaly Detection (WS-VAD) on Kaggle GPU T4 x 2
Architectural Innovations:

End-to-End Trainable from Scratch: Completely removes dependency on pre-trained DSANet checkpoints and frozen two-stage warm-starting (main-lr=0.0 is removed).
Dual GPU T4 x 2 Acceleration: Built-in torch.nn.DataParallel distributing batch workloads across both GPUs.
Automatic Dataset Discovery with # -> + Resolution: Automatically finds pre-extracted visual and audio .npy features, unzips archives if needed, and maps all Kaggle # -> + renamed files.
Multi-Scale Dilated Temporal Backbone (MDTBackbone): Windowed Attention + MDTP Dilations (1, 2, 4) with GLU.
Modality-Adaptive Branch (ModalityAdaptiveBranch): Multimodal Audio-Visual fusion for XD-Violence and automatic Motion-Residual mode (
) for silent UCF-Crime.
Gradient-Safe Prototype Alignment (GradientSafeRUPA): Controlled gradient detachment preventing prototype gradient collapse.
Quad-Stream Dynamic Safe Gate (QuadSafeGate): Dynamically routes 
 with safe bias initialization (-4.5).

def sync_csv_list(dataset_name, csv_rel_path, output_name):
    """Đồng bộ đường dẫn CSV gốc sang đường dẫn thực tế trên Kaggle."""
    input_csv = REPO_DIR / csv_rel_path
    output_csv = ARTIFACTS / output_name
    
    if not input_csv.exists():
        raise FileNotFoundError(f"Không tìm thấy file danh sách mẫu: {input_csv}")
        
    df = pd.read_csv(input_csv)
    resolved_paths = []
    missing_files = []
    
    for orig_path in df['path'].astype(str):
        base_name = Path(orig_path).name
        
        # Danh sách các biến thể tên khả dĩ
        candidates = [
            base_name,
            base_name.replace('#', '+'),
            base_name.replace('+', '#'),
            base_name.replace('#', '_'),
            base_name.replace('#', '')
        ]
        
        match = None
        for cand in candidates:
            if cand in file_map:
                match = file_map[cand]
                break
                
        if match:
            resolved_paths.append(match)
        else:
            missing_files.append(base_name)
            resolved_paths.append(orig_path)
            
    if missing_files:
        print(f"⚠️ Cảnh báo: Thiếu {len(missing_files)}/{len(df)} files cho {output_name}. Ví dụ: {missing_files[:3]}")
    else:
        print(f"✅ Đồng bộ 100% {len(df)} file cho {output_name} thành công!")
        
    df['path'] = resolved_paths
    df.to_csv(output_csv, index=False)
    return output_csv
